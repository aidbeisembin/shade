## Что сделано
- **«Настройки» не нажимались.** В браузере переход работал, а в окне Tauri на macOS переход на отдельную страницу зависает (та же причина, по которой встреча уже открывается на главной). Теперь настройки тоже открываются на главной: `/?view=settings&tab=…` через `history.pushState` (`lib/in-place-router.tsx`), все ссылки на `/settings` (сайдбар, «Скачать модель», вкладки) переводятся туда же. Прямой адрес `/settings` по-прежнему работает. Выбранность пункта в сайдбаре по параметру.
- **Обрыв при переходе.** Новый экран мягко проявляется (`.aid-page-in` в `Page`: прозрачность и сдвиг 6 px, 0,24 с), при `prefers-reduced-motion` без движения.
- **Кнопки окна в своей подложке** (второй круг ревью, вариант «над сайдбаром»): маленькая таблетка 72 × 22 px над сайдбаром, цвет между фоном окна и плитками, кнопки окна по её центру. Полосы во всю ширину больше нет, колонка страницы идёт во всю высоту. `src-tauri` не менялся.
- **Кнопка записи** 88 px вместо 72, микрофон 32 px, на 28 px от низа вместо 16; запас под капсулу 136 px.
