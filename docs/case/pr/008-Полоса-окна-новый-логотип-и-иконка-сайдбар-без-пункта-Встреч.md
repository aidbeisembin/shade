## Description

Двенадцатый круг, визуал: полоса окна, маскот с эмоциями, сайдбар без пункта «Встречи».

**1. Полоса окна.** На macOS сверху полоса 38 px на всю ширину (`WindowBar`). Цвет у неё как у фона окна в обеих темах.
- Окно перетаскивается за полосу и разворачивается двойным кликом. Это делает сам Tauri по атрибуту `data-tauri-drag-region`, нужные права в `tauri.conf.json` уже были.
- Кнопки окна стоят по центру полосы. Tauri, как и Electron, задаёт высоту зоны кнопок как высоту кнопки плюс `y` и ставит кнопки по её центру. При нынешних x 18, y 22 зона выходит 16 + 22 = 38 px, поэтому `tauri.conf.json` не менялся.
- Плитки начинаются ниже полосы через 8 px. На Windows и Linux заголовок окна системный, полосы нет. В браузере на заглушках кнопки окна нарисованы, чтобы видеть ту же раскладку.

**2. Сайдбар.**
- Пункта «Встречи» больше нет. На его месте знак ShadeNotes: живой маскот 28 px, клик ведёт к списку встреч, в том числе с экрана записи и со встречи.
- Внизу «Настройки», «Локально» и переключатель темы. Знак, который был внизу, убран. Кнопка «Назад» на встрече и в настройках осталась.

**3. Маскот.** Маскот перерисован из `shadenotes.png` в многослойный SVG.
- Слои: шипы, голова, тень, глаза (белок, зрачок, веко), брови, шесть форм рта, щёчка, точки «думаю» и «z».
- Живая версия: `src/aid/components/Mascot.tsx`. Статичный файл: `public/brand/shadenotes.svg`, лежит рядом с PNG, все слои подписаны по id, видна поза «подмигивает», как на иконке.
- Иконка приложения не менялась.

Из `portfolio-site` (`assistant-avatar.tsx`, `use-assistant-mood.ts`) взяты принципы, код свой:
- Машина настроений: idle, curious, thinking, speaking, happy, sleepy, error, wink и listening для записи.
- Минимальное время показа (`useHeldMood`): от 600 мс, «Рад» 1,4 с, «Ошибка» 1,6 с.
- Моргание по таймеру раз в 2,8–6 с, иногда двойное.
- Взгляд за курсором в спокойных настроениях.
- Короткие движения: lean, hop, shake, settle. Они играют на входе в настроение, settle изредка и в покое.
- Анимируются только `transform` и `opacity`. При `prefers-reduced-motion` движения, моргания и взгляда нет, а формы глаз и рта остаются (проверено: 0 анимаций, формы на месте).

Связь с приложением (`lib/mascot-mood.ts`):

| Состояние | Маскот |
|---|---|
| Список | покой, взгляд за курсором |
| Идёт запись | слушает; рот и глаза вздрагивают на каждый сигнал речи |
| «Не слышу речи» | любопытство с наклоном |
| Завершение записи | думает |
| Встреча сохранена | рад, прыжок |
| Тишина, запись не сохранена | сонный, «z» |
| «Не распознано» | ошибка, тряска |
| Генерация итогов | думает, готовые итоги 2,4 с «рассказывает» |

Где живёт маскот:
- сайдбар, 28 px;
- экран «Завершаем запись», 184 px;
- карточка «Тишина», 160 px;
- пустой список, 176 px.

**4. Экран «Завершаем запись».**
- В центре маскот вместо полосок.
- Заголовок по эмоции, от первого лица: «Слушаю последние секунды», «Сохраняю встречу», «Встреча сохранена».
- Пока решение не принято, итога нет. «Тишина. Сохранять нечего» или «Пара фраз. Сохранять не стали» появляются только после решения. Раньше в этот момент писалось «Речь не распознана. Проверяем последние секунды», хотя решение уже было принято.
- Капсула внизу больше не повторяет этот экран.

**Попутно.** На оранжевой карточке «Не распознано» у кнопки «Проверить звук» снова есть фон. Класс `bg-on-role/10` не собирался: цвет `on-role` задан без канала прозрачности.
