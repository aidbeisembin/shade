# Обратная связь

Читать перед правкой карточки «Как вам Shade?», формы в Настройках и функции `api/feedback`. Пути от `frontend/src/shade/`, если не сказано иное. Решение: `docs/case/decisions.md`, «Обратная связь».

## Где живёт

- **Карточка «Как вам Shade?»** (`components/feedback/FeedbackCard.tsx`): тихо, в стиле уведомлений, в доке слева внизу (`components/RecordDock.tsx`, перед подсказкой о речи), не модальная. Переживает переходы между страницами. Стекло `shade-glass shade-glass-dense`, ширина до 520 px; в плашке итога сжимается по содержимому, отступ со всех сторон 16 px (`useSpringWidth`). Уходит из дока обёрткой `components/DockLeave.tsx` тем же экземпляром, с последним видом.
- **Настройки → Общие → «Обратная связь»** (`FeedbackRows` в `pages/Settings.tsx`, после «Приватности»): раздел «Обратная связь»: строка «Оценка и отзыв» с формой (`components/feedback/FeedbackMorph.tsx`, звёзды и текст); строка-переключатель «Иногда спрашивать оценку», по умолчанию включён.
- **Функция** `frontend/api/feedback.ts`: Vercel Function проекта «shade» (корень `frontend`), пересылает отзыв в Telegram.

## Когда карточка приходит (`lib/feedback/policy.ts`, `offerVerdict`)

Проверки по порядку, первая сработавшая решает:

| Условие | Итог |
|---|---|
| Переключатель «Иногда спрашивать оценку» выключен | нет |
| Оценка уже ушла (`ratedAt`) | нет, больше никогда |
| Закрыта без отправки 2 раза (`MAX_DISMISSALS`) | нет, больше никогда |
| Идёт запись | нет; начало записи убирает карточку |
| Открыта не встреча, встреча в корзине | нет |
| Встреча восстановлена после сбоя (`recovered.json`) | нет |
| Встреча не из записи в этом окне (импорт, старая) | нет |
| Встреча успешно завершённая по счёту меньше 3-й (`MIN_COMPLETED`) | нет |
| С прошлого показа меньше 14 дней (`COOLDOWN_DAYS`) | нет |
| Итоги встречи не готовы (`summary.kind !== 'ready'`) | нет, ждём |
| Иначе | карточка через 1,5 с (`OFFER_DELAY_MS`) после открытия итогов |

«Успешно завершённая» значит: запись остановлена и встреча сохранена (`noteMeetingCompleted` в `lib/recording-controls.tsx`). Если проверка моделью убрала встречу в корзину, она из счёта выходит (`noteMeetingUncounted` в `lib/recording-outcome.tsx`), «Вернуть» возвращает. Номер встречи запоминается при завершении, поэтому вторая встреча не зовёт карточку и после третьей.

## Шаги (`lib/feedback/flow.ts`)

- **ask**: «Как вам Shade?», пять звёзд, подпись под ними. Звёзды жёлтые (`--star`), при наведении или выборе 1-2 мягко-красные (`--star-low`), цвет меняется за 200 мс.
- Оценка 3-5 (`sendsAtOnce`, выше `FORM_MAX = 2`) → **sending** сразу, без текста и без кнопки: щелчок по звезде и есть отправка (решение владельца 17.11.2026). Звезда допрыгивает (`FOLD_DELAY_MS` 450 мс), и когда ответ пришёл, карточка сжимается в плашку «Спасибо / Отзыв отправлен» с зелёной галочкой (`--ok`): высота и ширина на пружине soft, плашка проявляется из размытия. Пока ответа нет, видны звёзды без отклика. Через 1,6 с (`THANKS_HOLD_MS`, от появления плашки) карточка уходит из дока с размытием, с той же плашкой. Крестика на этом пути нет. Плашка `role="status"`, чтение с экрана её объявляет. Reduced motion: без ожидания прыжка.
- Оценка 1-2 → **form** «Что улучшить?»: звёзды (оценку можно поменять, форма остаётся), поле текста и кнопка «Отправить». Без «Отправить» ничего не уходит. Под полем только счётчик знаков, когда до предела меньше 200.
- Без значка слева и без строки «что уйдёт» под полем (решение владельца 17.11.2026: карточка тише). Что уходит, описано ниже, в «Что уходит и куда».
- Звезды на GitHub в карточке и в Настройках нет: она будет отдельной иконкой (`openGithub` в `components/feedback/FeedbackFields.tsx`, адрес `GITHUB_URL`).
- Наведение и стрелки ничего не отправляют: ветку выбирает только щелчок, Enter или пробел.
- **sending** → **sent** (та же сжатая плашка «Спасибо», «Отзыв отправлен» с зелёной галочкой и из формы, и сразу с карточки; через 1,6 с карточка уходит) / **queued** («Не получилось отправить, попробуем позже») и **failed** («Не получилось отправить»), карточка уходит через 4 с.
- Закрытие крестиком или Esc до отправки считается закрытием без оценки (`noteDismissed`). Повторный клик «Отправить» ничего не шлёт: запрос уходит один раз на входе в **sending**.
- Клавиатура: звёзды это `role="radiogroup"`, у звезды `role="radio"` и `aria-checked`, один Tab-стоп. Стрелки меняют оценку (без перехода через край), Home и End к краям, Enter и пробел подтверждают (выбирают ветку). В поле Cmd+Enter (Ctrl+Enter) отправляет, Esc отменяет.

## Форма в Настройках (механика Morph Popover, Kokonut UI, MIT; `THIRD_PARTY_NOTICES.md`)

- Кнопка «Написать отзыв» вырастает в форму (ширина 200 → 380, высота и радиус на одной пружине), подпись кнопки переезжает в заголовок формы.
- Колонка строки 200 px. Форма 380 px растёт влево и вниз поверх строки «Иногда спрашивать оценку»; строка последняя в плитке, поэтому пока форма раскрывается, плитка докручивается вслед за её нижним краем (в такт пружине), и «Отправить» не уходит под кромку.
- Размер, радиус и положение подписи оболочки ставит только `draw` (layout-эффект до первой отрисовки), не `style` в разметке: React переписал бы его при перерисовке, и щелчок по звезде сжимал форму до ширины колонки.
- При открытии фокус в поле, после закрытия обратно на кнопку. Esc и щелчок вне формы закрывают, Cmd+Enter отправляет.
- После отправки форма сжимается в плашку «Спасибо» с галочкой и через 1,6 с (`THANKS_HOLD_MS`) снова кнопка. При очереди или отказе форма закрывается, тост «Не получилось отправить, попробуем позже» (очередь) или «Не получилось отправить» (тело отвергнуто).
- Переключатель «Иногда спрашивать оценку» не влияет на форму в Настройках: она есть всегда.

## Что уходит и куда

- Тело `POST` на основной адрес `https://aidbeisembin.com/shade/api/feedback` (портфолио владельца пересылает его на проект Vercel «shade»), при сетевой ошибке или ответе 404 и 405 на запасной `https://meetily-tau.vercel.app/api/feedback` (`FEEDBACK_URLS` в `lib/feedback/send.ts`). Ответ функции на основном (2xx, 4xx, 429, 5xx) окончательный. Тело ровно `{rating, text, appVersion, macos, locale}` (`frontend/api/_contract.ts`, общий с функцией; приложение берёт его через `lib/feedback/contract.ts`). Текст до 2000 знаков (по кодовым точкам, эмодзи не рвутся), поле приложение обрезает само.
- `macos` всегда `unknown`: WebKit замораживает версию в User-Agent на 10.15.7, а честный путь (плагин os или чтение `SystemVersion.plist`) требует правки ядра. Записи и текст встреч не отправляются никогда.
- Статистику Shade не собирает: отзыв по кнопке единственное, что приложение отправляет само.
- Домены в CSP ядра: `connect-src` в `src-tauri/tauri.conf.json`, оба адреса (`docs/isolation.md`, разделы 9 и 10).

## Отказы (`lib/feedback/send.ts`)

| Что случилось | Что делает Shade |
|---|---|
| Основной адрес недоступен (сеть, CORS, тайм-аут 10 с) или отвечает 404, 405 | та же попытка уходит на запасной адрес |
| Нет сети, сеть рвётся, тайм-аут 10 с на обоих адресах | в очередь, «попробуем позже» |
| Функция отвечает 503 (не заданы переменные) | в очередь, «попробуем позже» |
| 429 (частота) или 5xx (Telegram не принял: 502) | в очередь |
| 400, 413 (тело не по договору) | не в очередь (повтор не поможет), «Не получилось отправить» |
| Очередь | уходит при следующем запуске (`flushFeedbackOnLaunch` в доке), не больше 3 попыток (`MAX_ATTEMPTS`), в очереди не больше 10 отзывов |
| Нет `localStorage` | отправка работает, очередь молча теряется |

Отзыв в очереди считается оценкой: карточка больше не приходит.

## Функция `frontend/api/feedback.ts`

- Next.js собирает сайт статикой (`output: 'export'`), свои маршруты API у него невозможны; папку `api/` Vercel собирает отдельно как функции.
- Vercel компилирует файлы `api/` по одному, без сборщика, поэтому `api/package.json` с `"type": "module"` и импорт с явным `.js` (`./_contract.js`). Без этого Node грузит функцию как CommonJS и отвечает 500 `FUNCTION_INVOCATION_FAILED`. Импортировать из `src/` функция не может: тот код не ES-модуль для Node. Файлы с `_` Vercel функциями не считает.
- Ответы: OPTIONS 204; не POST 405; нет переменных 503; больше 5 отзывов с адреса за 10 мин 429; тело больше 9000 байт 413; не JSON или не по договору 400; Telegram не принял или недоступен (8 с) 502; иначе 200.
- Счёт частоты в памяти экземпляра функции: новый экземпляр начинает счёт заново. Для одного канала отзывов этого хватает; если начнут засыпать, нужен общий счётчик (Vercel KV, Upstash).
- Сообщение простым текстом, без `parse_mode`: «Shade · ★★☆☆☆ 2/5», текст или «(без текста)», строка «Shade {версия} · macOS {версия} · {язык}». Текст отзыва в журнал функции не пишется.
- CORS только для окна Shade: `tauri://localhost` (macOS), `http(s)://tauri.localhost` (Windows, Linux), `http://localhost:3118` (разработка).
- Переменные окружения Vercel (не в репозитории): `SHADE_FEEDBACK_BOT_TOKEN`, `SHADE_FEEDBACK_CHAT_ID`.

## Хранилище (`localStorage`, новые ключи)

| Ключ | Что |
|---|---|
| `shade.feedback.prompt.v1` | JSON `{total, completed: [{id, n}], shownAt, dismissals, ratedAt}`: счёт завершённых встреч (последние 50), последний показ, закрытия, время оценки |

## Движение (`lib/motion/`, движок @umbra/motion)

Движок пружин поставлен из реестра Umbra (`components.json`, `registries.@umbra`), файлы `spring.ts`, `presets.ts`, `use-spring.ts` без правок. Свои значения образцов в `lib/motion/shade-springs.ts`. Числа сняты `simulate()` движка, 60 кадров в секунду.

| Свойство | Пружина (k/c) | Перелёт | До покоя | Что при прерывании |
|---|---|---|---|---|
| Заливка звезды (`--shade-star-fill`, `clip-path`) | 300/24, ζ 0,69 | 4,9 % (зажата в 0..1) | 567 мс | новая цель с текущей скоростью; очередь зажигания (шаг 50 мс через `after()`) отменяется, гаснут в обратном порядке |
| «Прыжок» звезды (`transform: scale`) | 520/13, ζ 0,29, старт 0,7, толчок 7 | пик 1,188 | 850 мс | только при зажигании; повторное зажигание начинает с 0,7 заново |
| Подпись под звёздами (перекат, `translateY` и прозрачность) | 260/22, ζ 0,68 | 5,3 % | 617 мс | новая подпись берёт текущее положение, старая уходит с места |
| Кнопка → форма → плашка (ширина, высота, радиус, переезд подписи) | soft Umbra 260/24, ζ 0,74 | 3,0 % | 483 мс | обратный ход с текущего места и скорости, без скачка |
| Высота карточки между шагами | soft 260/24 | 3,0 % | 483 мс | так же |
| Ширина карточки: звёзды и форма (до 520 px) → плашка итога (по содержимому) | soft 260/24 | 3,0 % | 483 мс | содержимое сразу в итоговой ширине и по центру, рамка догоняет и обрезает края поровну; окно и язык меняют ширину без пружины |
| Цвет звёзд: жёлтый ↔ мягко-красный | CSS 200 мс | | 200 мс | с текущего цвета |

Reduced motion (`prefers-reduced-motion`): сразу итог, без прыжков, очереди и переката.

Записи ×0,25: `docs/screenshots/shade-feedback/motion/` (звёзды; форма Shade рядом с образцом Kokonut UI). Замедление одинаковое для Shade и образца: подменённые часы Playwright (`page.clock`: rAF, таймеры, `performance.now`), 4 мс страницы за 16 мс реального времени. Образец «Star Rating» (DesignBookmark) без ссылки, поэтому звёзды записаны без соседа; их значения в таблице выше. `?motion=0.25` на заглушках замедляет пружины и таймеры движка (запись экрана ×0,25).

## Заглушки (`?mock=…`)

- `?feedback-card=ask|low|high|sent|queued` показывает карточку на нужном шаге без условий (`lib/feedback/preview.ts`); `high` это уже нажатые 5 звёзд: оценка уходит в заглушку, карточка сжимается в плашку «Спасибо» и уходит.
- `?feedback=ok|503|offline|400` задаёт ответ отправки (`mockFetch` в `lib/feedback/store.ts`); по умолчанию `ok`.
- Пример: `localhost:3118/?mock=full&feedback-card=low&feedback=offline`. Английский: `?mock=demo-en`.
