# Страница встречи

Читать перед правкой страницы встречи: шапка, итоги, транскрипт, длительность. Перенесено из CLAUDE.md. Пути от `frontend/src/shade/`.

## Раскладка (`pages/MeetingDetails.tsx`)
- Дочерний экран: полоса с «Назад» и действиями таблетками ([frame.md](frame.md#шапка-componentspagetsx)).
- Большое название 36/40 и мета подписью и значением на фоне окна. Дата в мете есть всегда (у названия по дате она раньше не показывалась, и мета «прыгала» бы, когда название придумывается позже).
- Итоги: белая полоса-заголовок, как плитка транскрипта (`bg-card`, серый круг `bg-muted` под значком, без цвета роли; итоги не акцент экрана, решение владельца 2026-11-17) с серым шевроном `CaretDown` `bold` справа, ниже плитка транскрипта. Полоса есть только когда итоги есть: их запускает человек кнопкой «Подвести итоги» (сама Shade итоги не делает). Колонка текста `MEASURE`.
- Без текста плитка Giants «Речь не распознана» с действиями («Скачать модель», если её нет; «Открыть папку», «Удалить»). «Распознать заново» (диалог, меню «Ещё») убрано по просьбе владельца 2026-11-17: ядро (`audio/retranscription.rs`) осталось, интерфейс его не зовёт. Правило двух плиток теперь про Giants и цветные плитки других экранов ([foundations.md](foundations.md#правило-двух-плиток)).
- Кнопки записи в покое здесь нет; капсула идущей записи и итог показываются ([recording.md](recording.md)).

## Итоги
- «Подвести итоги» (`variant="secondary"`, нейтральная кнопка, без цвета роли, свечений и градиентов) только когда есть из чего: запись остановлена (во время записи кнопки нет) и в тексте не меньше `MIN_SUMMARY_WORDS` слов (`lib/speech.ts`). Итоги, сделанные раньше, видны при любой длине.
- Пока итоги готовятся: та же белая полоса, что у готовых (та же высота), одной строкой по центру: в круге `Spinner`, «Готовим итоги» и серая подсказка на одной линии (двухстрочный блок «уезжал» вниз от центра круга). Плитки-заглушки (`Skeleton`) под полосой нет: текст итогов появляется, когда он готов (решение владельца 2026-11-17).
- У готовых итогов кнопки «Сделать заново» нет (убрана по просьбе владельца 2026-11-17): итоги делаются один раз. «Повторить» остаётся только у ошибки итогов.
- Генерация итогов «думает» свечением голоса: [foundations.md](foundations.md#эффекты).

## Длительность
- Длительность встречи (строка списка, страница встречи) это длина файла звука `audio.mp4` в папке записи (`lib/recording-duration.ts`, заголовок mvhd, файл целиком не читается), а не конец последней реплики. Ядро длительность записи не хранит: `duration_seconds` в metadata.json тоже конец реплики.
- Нет файла: как раньше, конец последней реплики.

## Название встречи (`lib/meeting-title.ts`, `lib/title-service.ts`)
Название по сути разговора вместо «Встреча 16 ноября, 15:02»: коротко, 2-3 слова и не больше 30 знаков (вдвое короче прежних 6 слов и 60 знаков, по просьбе владельца 2026-11-17), тема, на языке разговора, без кавычек и точки, с заглавной, без имён и сумм. Решение и отвергнутое: `docs/case/decisions.md`, «Названия встреч».
- **Кто и когда** (`TitleMode` в `lib/title-core.ts`): `auto` сама после «Остановить» и после восстановления из сбоя, только локальная модель итогов (встроенная, Ollama на этом компьютере); `after-summary` когда человек нажал «Подвести итоги» (следит `watchSummary` по состоянию итогов в ядре, страница может быть закрыта). Других путей нет: «Придумать название заново» в меню и «Придумать названия для старых встреч» в Настройках убраны по просьбе владельца 2026-11-17. Облачному провайдеру автоматически ничего не уходит: у `auto` запрос не начинается, текст даже не читается. Запрет повторён в ядре (`allow_cloud`).
- **Кому положено**: название по умолчанию (`isDefaultTitle`: `Meeting ДД_ММ_ГГ_ЧЧ_ММ_СС`, «Встреча/Meeting <дата, время>»), запись от минуты (`MIN_TITLE_SECONDS`), от 20 слов текста без галлюцинаций.
- **Ручное главнее**: переименование (`renameMeeting`) сначала ставит пометку `manual` в `title.json` папки встречи (ядро, рядом с `recovered.json`), потом сохраняет название; автоматика такую встречу не трогает ни после итогов, ни после «Остановить». Запись автоматикой идёт командой `api_set_auto_title(ожидаемое, новое)`: если название изменилось за время запроса, не пишет. Из ядра итогов убрано переименование по заголовку `# …` из текста итогов.
- **Отказ**: нет модели, ошибка, пустой, общий или не на языке ответ: название остаётся прежним (датой), без уведомлений, в консоль окна и в журнал ядра строка с причиной, без текста встречи.
- **Запись идёт**: автоназвание ждёт конца записи (локальная модель и распознавание делят процессор).
